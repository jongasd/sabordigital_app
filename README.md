# 🍽️ SaborDigital

Aplicação desenvolvida para oferecer uma experiência digital de acesso e gerenciamento de informações relacionadas a restaurantes, pratos e pedidos.

O **SaborDigital** tem como objetivo facilitar a interação entre clientes e estabelecimentos por meio de uma interface simples, moderna e intuitiva.

> 🚧 **Projeto em desenvolvimento**

---

## 📌 Sobre o projeto

O **SaborDigital** é um projeto voltado para o setor alimentício, buscando transformar processos tradicionais de atendimento e consulta de cardápio em uma experiência digital.

A aplicação foi desenvolvida com foco em:

* Facilidade de utilização
* Organização das informações
* Interface intuitiva
* Responsividade
* Experiência do usuário
* Estrutura organizada para evolução do projeto

---

## ✨ Funcionalidades

Entre as funcionalidades previstas/implementadas no projeto estão:

* 📋 Visualização de produtos e pratos
* 🔎 Busca por itens
* 🏷️ Organização por categorias
* 🛒 Gerenciamento de pedidos
* 👤 Gerenciamento de usuários
* 📱 Interface adaptada para dispositivos móveis
* 💾 Persistência de dados
* 🔄 Integração com serviços e APIs

> As funcionalidades podem variar de acordo com a versão atual do projeto.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/jongasd/sabordigital_app.git
```

### 2. Acesse a pasta

```bash
cd sabordigital_app
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm start
```

> O comando de execução pode variar conforme o framework utilizado.

## 🔐 Variáveis de ambiente

Caso o projeto utilize APIs, banco de dados ou outros serviços externos, crie um arquivo `.env` na raiz do projeto.

Exemplo:

```env
API_URL=
DATABASE_URL=
```

Não compartilhe informações sensíveis, como senhas, tokens ou chaves de API no repositório.
